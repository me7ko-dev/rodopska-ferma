# Родопска ферма 🌄

3D игра за ферма в Родопите. Сади пшеница, царевица, смилянски фасул и още култури. Гледай кокошки, крави, овце, кози и пчели. Прави хляб, баница, родопско кисело мляко, лютеница и баклава. Изпълнявай поръчки на хората от селото, купувай къщи, които носят наем, и коли, които можеш да караш из селото.

**Играй (телефон и компютър):** https://me7ko-dev.github.io/rodopska-ferma/

- **Хранилище в GitHub:** https://github.com/me7ko-dev/rodopska-ferma
- **На телефона:** отвори линка в Chrome → меню ⋮ → „Добавяне към началния екран“. Играта тръгва и без интернет.

## Какво има в играта

| | |
|---|---|
| 🌾 14 култури | пшеница, царевица, картофи, моркови, цвекло, смилянски фасул, домати, чушки, слънчоглед, тиква, зеле, ягоди, лавандула, мурсалски чай |
| 🐔 5 вида животни | кокошки, крави, овце, кози, пчели |
| 🏭 11 работилници | фуражна мелница, пекарна, мандра, захарна фабрика, сокоизстисквачка, тъкачница, маслобойна, консервна работилница, сладкарница, билкарница |
| 🍎 4 плодни дървета | ябълка, слива, череша, орех |
| 🏡 Имоти | 5 нива на твоята къща и 12 къщи в селото, които носят наем |
| 🚗 10 коли | мотор, хечбек, пикап, трактор, седан, джип, камион, такси, спортни коли — всяка може да се кара |
| 📋 Поръчки и посетители | хората от селото поръчват стоки и идват до фермата |

## Как се играе

- **Ниви:** натисни празна нива и избери семе. Плъзни пръст по другите празни ниви — засяват се всички. Когато узреят, плъзни по тях, за да ги ожънеш.
- **Работилници:** натисни сградата и избери какво да се прави.
- **Животни:** натисни заграждението, за да ги нахраниш, а после — за да събереш продуктите.
- **Камера:** местиш с пръст, приближаваш с два пръста или с колелцето, въртиш с два пръста, с десния бутон или с Q и E.
- **Каране:** с джойстика на екрана или със стрелките и W A S D.

## За разработчици

```
npm install
npm run dev        → http://localhost:5191
npm run build      → папка dist
npm run deploy     → публикуване в GitHub Pages
npm run play       → робот, който изиграва играта (иска Playwright и пуснат dev сървър)
```

Направено с [three.js](https://threejs.org) и TypeScript (Vite). Звуците и музиката се създават в браузъра (Web Audio).

3D моделите са от [poly.pizza](https://poly.pizza) — повечето на **Quaternius** (CC0). Авторите на моделите с лиценз CC-BY 3.0 са в [CREDITS.md](CREDITS.md).
