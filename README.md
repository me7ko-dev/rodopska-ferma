# Родопска ферма 🌄

3D игра за ферма в Родопите. Сади пшеница, царевица, смилянски фасул, родопски боровинки, маслодайна роза и още много. Гледай кокошки, крави, овце, кози, пчели, патици, прасета, биволи, лами и пъстърва. Прави хляб, баница, шопска салата, пататник, лютеница, сладолед, розово масло и родопски носии. Изпълнявай поръчки, купувай къщи и коли — и играй с приятели онлайн.

**Играй (телефон и компютър):** https://me7ko-dev.github.io/rodopska-ferma/

- **Хранилище в GitHub:** https://github.com/me7ko-dev/rodopska-ferma
- **На телефона:** отвори линка в Chrome → меню ⋮ → „Добавяне към началния екран“. Играта тръгва и без интернет.
- **За Windows:** програмата се сглобява автоматично — раздел [Releases](https://github.com/me7ko-dev/rodopska-ferma/releases/latest), файл `RodopskaFerma-windows.zip`.

## Как се играе

- **Ниви:** натисни празна нива и избери семе. Плъзни пръст по другите празни ниви — засяват се всички. Когато узреят, плъзни по тях, за да ги ожънеш.
- **Работилници:** натисни сградата и избери какво да се прави. Опашката може да се разшири с монети.
- **Животни:** натисни заграждението, за да ги нахраниш, а после — за да събереш продуктите.
- **Съседи:** бутонът „Съседи“ — направи си профил, добави приятели, ходи им на гости и им помагай (поливаш нивите, храниш животните). В „Сергия“ има пазар, на който купуваш и продаваш на други играчи.
- **Камера:** местиш с пръст, приближаваш с два пръста или с колелцето, въртиш с два пръста, с десния бутон или с Q и E.
- **Каране:** с джойстика на екрана или със стрелките и W A S D.
- **Град:** бутонът „Град“ долу вдясно прелита до града (и обратно до фермата). Докосни гарата, за да видиш кога идва влакът.

## Онлайн и лични данни

Профилът е само **име и парола** — без имейл и без телефон. Паролата се пази защитена (PBKDF2). Другите играчи виждат името ти, нивото и фермата ти. Няма чат. Профилът може да се изтрие от самата игра (Съседи → Профил).

## За разработчици

```
npm install
npm run dev        → http://localhost:5191
npm run build      → папка dist
npm run deploy     → публикуване в GitHub Pages
npm run play       → робот, който изиграва играта (иска Playwright и пуснат dev сървър)
node test/sim.mjs 10      → баланс: 10 часа игра, превъртени бързо
node test/buildall.mjs    → купува и поставя всяка сграда
```

**Онлайн сървърът** е в папка `server/` (Cloudflare Worker + база D1):

```
npx wrangler dev -c server/wrangler.jsonc --port 8799     → сървър на компютъра
node test/online.mjs                                      → 46 проверки на сървъра
node test/online-ui.mjs                                   → двама играчи в два браузъра
npx wrangler deploy -c server/wrangler.jsonc              → качване
```

Направено с [three.js](https://threejs.org) и TypeScript (Vite). Звуците и музиката се създават в браузъра (Web Audio).

3D моделите са от [poly.pizza](https://poly.pizza) — повечето на **Quaternius** (CC0), както и Kenney, Kay Lousberg, CreativeTrio и други. Авторите на моделите с лиценз CC-BY 3.0 са в [CREDITS.md](CREDITS.md).
